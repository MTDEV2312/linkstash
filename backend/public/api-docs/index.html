LinkStash API Docs

API REST para gestion de enlaces, etiquetas y panel de control. Todas las rutas bajo /api usan JSON, salvo uploads en multipart/form-data.

Base URL

http://localhost:5000

Version

v2.0.0 (segun respuesta de /)

Rate limit

Ventana por defecto: 60s, max 60 requests (configurable).

Los headers X-Request-ID y X-Response-Time se exponen en respuestas.

Autenticacion

Las rutas privadas requieren header Authorization: Bearer <token>. El token dura 7 dias.

{
  "Authorization": "Bearer eyJhbGciOi..."
}

Formato de errores

Los errores estandar incluyen success, message, errorCode y requestId.

{
  "success": false,
  "message": "Token invalido",
  "errorCode": "INVALID_TOKEN",
  "requestId": "req_123"
}

Errores de validacion pueden incluir errors con detalles por campo.

{
  "success": false,
  "message": "Validacion fallida",
  "errors": [
    { "field": "email", "message": "Debes proporcionar un email valido" }
  ]
}

/api/auth

POST /api/auth/register

Registro de usuario.

{
  "username": "string (3-20, alfanum)",
  "email": "string (email)",
  "password": "string (min 6, mayus, minus, numero, especial)"
}
{
  "success": true,
  "message": "Usuario registrado exitosamente",
  "data": {
    "token": "jwt",
    "user": { "id": "...", "username": "...", "email": "...", "createdAt": "...", "updatedAt": "..." },
    "expiresIn": "7d"
  }
}
POST /api/auth/login

Login.

{
  "email": "string",
  "password": "string"
}
{
  "success": true,
  "message": "Inicio de sesion exitoso",
  "data": { "token": "jwt", "user": { "id": "..." }, "expiresIn": "7d" }
}
GET /api/auth/me Privado

Perfil del usuario actual.

{
  "success": true,
  "message": "Perfil obtenido",
  "data": { "user": { "id": "..." } }
}
PUT /api/auth/profile Privado

Actualizar username y/o email.

{
  "username": "string",
  "email": "string"
}
{
  "success": true,
  "message": "Perfil actualizado exitosamente",
  "data": { "user": { "id": "..." } }
}
PUT /api/auth/change-password Privado

Cambiar password.

{
  "currentPassword": "string",
  "newPassword": "string"
}
{
  "success": true,
  "message": "Contrasena actualizada exitosamente"
}

/api/links

GET /api/links Privado

Listado paginado con filtros.

QueryTipoNotas
pageintdefault 1
limitintmax 50, default 20
searchstringtexto libre
tagsstringlista separada por coma
archived"true"|"false"default false
favorite"true"|"false"|""default ""
sortBycreatedAt|title|lastVisited|clickCountdefault createdAt
sortOrderasc|descdefault desc
 
{
  "success": true,
  "data": {
    "links": [ { "id": "..." } ],
    "pagination": {
      "currentPage": 1,
      "totalPages": 3,
      "totalLinks": 42,
      "hasNextPage": true,
      "hasPrevPage": false
    }
  }
}
POST /api/links/save-link Privado

Guardar enlace. Si no se envia title, se procesa metadata y devuelve 202.

{
  "url": "string (http/https)",
  "title": "string (opcional)",
  "description": "string (opcional)",
  "tags": ["string"]
}
{
  "success": true,
  "message": "Link guardado, procesando metadata...",
  "data": { "link": { "id": "...", "status": "processing" } }
}
POST /api/links Privado

Alias compatible de /save-link.

GET /api/links/:id Privado

Obtener un enlace por ID.

PUT /api/links/:id Privado

Actualizar enlace. Acepta JSON o multipart/form-data con campo image y uploadToCloudinary=true.

{
  "title": "string",
  "description": "string",
  "image": "string (url o ruta /defaults/...) ",
  "tags": ["string"],
  "isFavorite": true,
  "isArchived": false,
  "uploadToCloudinary": true
}
DELETE /api/links/:id Privado

Eliminar enlace.

POST /api/links/:id/click Privado

Incrementar contador de clicks.

POST /api/links/:id/favorite Privado

Alternar favorito.

POST /api/links/:id/archive Privado

Alternar archivado.

POST /api/links/batch Privado

Operaciones en lote: delete | archive | unarchive | addTag.

{
  "action": "delete|archive|unarchive|addTag",
  "linkIds": ["id1", "id2"],
  "tag": "string (requerido solo para addTag)"
}
{
  "success": true,
  "modified": 2,
  "action": "archive"
}
